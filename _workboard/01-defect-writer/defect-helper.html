📝 กรอกรายละเอียด Defect

รูปแบบที่ดี: "[โมดูล] อาการ + ที่ไหน + เมื่อไร" เช่น "[Checkout] ปุ่มชำระเงินไม่ทำงานเมื่อใช้คูปองหมดอายุ"

ระบุ OS / Browser / เวอร์ชัน build ให้ชัดเจน — ช่วยให้ dev reproduce ได้ตรงจุด

สภาพแวดล้อม/สถานะก่อนเริ่มทำซ้ำ เช่น login ด้วย role อะไร, มีข้อมูลอะไรอยู่ก่อนแล้ว

1 action ต่อ 1 บรรทัด เริ่มจาก state ที่ชัดเจน ระบุค่าที่กรอกจริงถ้าเกี่ยวข้อง

ระบบควรทำอะไร — อ้างอิงจาก spec/requirement ถ้ามี

สิ่งที่เกิดขึ้นจริง — เจาะจง ไม่คลุมเครือ (หลีกเลี่ยง "ไม่ทำงาน" เฉยๆ)

อธิบายว่ามีหลักฐานอะไรแนบ (screenshot, log, video) แม้ไฟล์แนบจริงต้องอัปโหลดแยกใน tracker
